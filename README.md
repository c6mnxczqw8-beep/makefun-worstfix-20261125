# Worst Fix Ever: Funniest Commit Message — entry

A program/v1 entry for the make.fun "Worst Fix Ever: Funniest
Commit Message" bounty. `main.py` writes one commit message to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when
that variable is set).

The commit message:

> fix: cured the memory leak by deleting the memory; uptime is now measured in seconds

It reads exactly like a real history entry -- conventional
prefix, total confidence -- while the fix it describes quietly
ends the product. The leak is gone. So is everything the leak
was leaking from. A refinement pass added the deadpan
consequence clause ("uptime is now measured in seconds"),
logged as a metric by an author who noticed the catastrophe
and shipped it anyway. 86 characters. See `CANDIDATES.md` for
the full draft list this winner was picked from.
